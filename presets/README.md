# presets/ — библиотека пресетов анимации

Инструменты MCP: `list_presets`, `apply_preset`. Имя пресета — путь от этой папки без расширения (`fade-up`, `lesson/title-in`).

## Пресеты-данные (`*.json`)

Движение ключами в **кадрах при 24 fps** — как в таблице Уильямса (`/animation-craft` §3); под fps композиции
пересчитываются сами, ключи встают на кадр. Ease задаётся **на отрезок**: `out` — выход из ключа, `into` — вход в следующий,
поэтому антиципация (мягкая остановка) и падение с ускорением живут в одном пресете.

```json
{
  "description": "что делает — одной строкой",
  "use": "когда брать (и ссылка на правило ремесла)",
  "tracks": [
    { "prop": "opacity",  "mode": "absolute", "keys": [[0, 0], [8, 100]], "ease": "soft" },
    { "prop": "position", "mode": "offset",   "keys": [[0, [0, 40]], [12, [0, 0]]], "ease": "snap" },
    { "prop": "scale",    "mode": "factor",   "keys": [[0, 0], [7, 110], [11, 100]], "ease": { "out": 20, "into": 90 } },
    { "prop": "scale",    "expression": "… $start …" }
  ]
}
```

- `prop`: `opacity`, `position`, `scale`, `rotation`, `anchor`.
- `mode`: `absolute` — значение как есть · `offset` — прибавить к текущему · `factor` — текущее × v / 100. Для offset/factor слой сначала ставят в **конечное** положение, пресет приводит его туда.
- `ease`: `snap` {20, 90} · `soft` {60, 60} · `punch` {10, 95} (как `KB_EASE` кита) · `linear` · `hold` · `{ "out": n, "into": n }`.
- `expression`: выражение на свойство; `$start` заменяется временем старта (с).
- `apply_preset … speed: 1.5` — в полтора раза медленнее.

| Пресет | Что | Кадров (24 fps) |
|---|---|---|
| `fade-in` / `fade-out` | непрозрачность, soft | 8 |
| `fade-up` | проявление + подъём на 40 px, snap | 12 |
| `pop-in` | масштаб 0 → 110 → 100, перелёт на 0,6 | 11 |
| `slide-in-left` | въезд слева −400 → +12 → 0 | 14 |
| `accent-punch` | антиципация 94 % → удар 112 % → 100 %; start на 3–4 к. раньше ударного слога | 12 |
| `drop-out` | антиципация вверх 20 px → падение 300 px с ускорением, угасание | 12 |
| `breathe` | выражение: дыхание ±0,8 % по вертикали, период 3 с (moving hold) | — |

## Свои `.ffx` из After Effects

Настроить анимацию на слое → выделить свойства или эффекты → **Animation → Save Animation Preset…** → сохранить сюда
(можно в подпапку). Рядом можно положить `<имя>.md`: первая строка станет описанием в `list_presets`.
`.ffx` применяется от `start` штатно (AE ставит ключи от индикатора времени).

Штатные пресеты Adobe (~600) доступны как `adobe:<путь>` без копирования: `list_presets source=adobe query=Behaviors`.
